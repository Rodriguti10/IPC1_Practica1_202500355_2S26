# Sistema de Estacionamiento de Vehiculos (IPC1 - Practica 1)

Aplicacion de consola en Java que simula un estacionamiento de 8x8 espacios,
dentro de un tablero completo de 10x10 (con via exterior, entrada y salida
generadas aleatoriamente). Proyecto Maven organizado en clases: Vehiculo,
ValidadorPlaca, Lector, Tablero, Caja, Estacionamiento y Practica1.

## Como compilar
mvn clean package

## Como ejecutar
java -jar target/practica1-1.0-SNAPSHOT.jar

## Menu
1. Ingresar vehiculo
2. Retirar vehiculo
3. Mostrar estacionamiento
4. Buscar vehiculo por placa
5. Mostrar ruta mas corta
6. Mostrar ingresos
7. Salir
